# Minimal Neon Portfolio

Готовый одностраничный портфолио-сайт на чистых HTML/CSS/JS.

## Что внутри
- `index.html` — структура и весь контент
- `styles.css` — адаптивный дизайн, сетка, типографика, неоновая палитра без свечения
- `script.js` — EN/RU переключатель, мобильное меню, копирование e-mail
- никаких библиотек, сборщиков и внешних зависимостей
- адаптивная верстка
- `prefers-reduced-motion`
- семантическая разметка и focus states

## Перед публикацией
1. В `index.html` замени `your.email@example.com`.
2. Замени ссылки `href="#"` на LinkedIn / Behance.
3. При желании добавь имя в brand/hero и реальные case studies.
4. Не выдавай учебные работы за коммерческие — текущая версия специально формулирует опыт честно.

## Как открыть
Просто открой `index.html` в браузере.

Для локального сервера:
```bash
python -m http.server 8000
```

## Дизайн-направление
Сайт создан с нуля. В основу легли паттерны современных award-winning портфолио: сильная типографика, модульная сетка, контент важнее эффектов, высокая контрастность, акцентный цвет без glow, минимум анимаций, короткие подписи, адаптивность и доступность.

Исходный код чужих портфолио не копировался.
